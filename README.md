# Імітаційна модель інформаційної системи обробки завдань трьох типів (варіант B14)

Курсова робота з освітнього компонента «Моделювання систем. Курсова робота»
(КПІ ім. Ігоря Сікорського). Тема: «Імітаційна модель інформаційної системи обробки завдань
трьох типів з пріоритетним упорядкуванням черги на основі формального опису стохастичною
мережею Петрі».

Система обробляє завдання типів A, B і C: завдання A і B виконуються одночасно в межах
оперативної памʼяті, завдання C монополізує систему. Досліджено вплив п'яти стратегій
упорядкування черги (A > B > C, B > A > C, C > B > A, C > A > B, C > (A = B)) за різних
інтенсивностей надходження на середній час перебування завдання в системі, середню кількість
завдань у черзі та середній час очікування в черзі.

## Структура

| Каталог | Вміст |
|---|---|
| `sim/` | Програма на Java 23 (Maven): розширення ядра `petri-math`, модель B14, верифікація, експерименти, тести JUnit 5 |
| `experiments/` | Результати прогонів (CSV), результати верифікації, скрипти аналізу на Python і їхні результати |
| `model/` | Мережа Петрі у форматі PNML (редактор PetriObjModelPaint) і її зображення |
| `thesis/` | Пояснювальна записка (LaTeX, клас `kpi-thesis`) |

Пакети програми (`sim/src/main/java/ua/kpi/km/b14`):

- `petri` — розширення ядра: стохастичний перехід, розвʼязання конфліктів, цикл імітації однієї мережі;
- `model` — мережа B14, параметри, стратегії, обчислення вихідних характеристик;
- `verification` — інваріанти, протокол подій, порівняння з аналітичною моделлю M/M/c;
- `experiment` — серії прогонів експериментального дослідження;
- `io`, `app` — запис файлів і запуск із командного рядка.

## Вимоги

- JDK 23+, Maven, [just](https://github.com/casey/just);
- ядро `petri-math` 2.6.0 у локальному репозиторії Maven:
  `mvn install` у клоні [PetriObjModelPaint](https://github.com/StetsenkoInna/PetriObjModelPaint);
- Python 3 для аналізу (`experiments/requirements.txt`).

## Запуск

```bash
cd sim
just test          # компіляція і тести
just run 3 0.6     # один прогін: стратегія 3, γ = 0,6
just verify        # серії прогонів верифікації → experiments/verification
just experiments   # експериментальне дослідження → experiments/results, аналіз → experiments/analysis
```

Перед `just experiments` потрібне віртуальне середовище Python:

```bash
python3 -m venv experiments/.venv
experiments/.venv/bin/pip install -r experiments/requirements.txt
```

Усі прогони мають фіксований seed, тож результати відтворюються.
